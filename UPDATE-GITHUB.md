# Updating the live GitHub Pages site

This folder is ready to replace the current Gauras Tours site.

## On iPhone / GitHub mobile web
1. Download and unzip the updated ZIP on your iPhone.
2. Open your `gauras-tours` repository on GitHub in Safari/Chrome.
3. Open the repository's **Code** tab.
4. Tap **Add file** → **Upload files**. If you do not see it, use your browser menu and choose **Request Desktop Website**.
5. In the iPhone file picker, open the unzipped folder and select **all files and the `assets` folder contents**. GitHub Pages needs the files themselves, not the ZIP file.
6. Upload them to the repository root, replacing the existing files with the same names.
7. Add a commit message such as `Update site photos and mobile layout`, then tap **Commit changes**.
8. If prompted about duplicate names, overwrite/replace the existing files.
9. GitHub Pages normally republishes after the commit. Refresh the live site after a minute or two.

Important: `index.html`, `styles.css`, `script.js`, `booking.html`, `details.html`, `favicon.svg`, and the full `assets` folder should all be at the repository root in the same structure as this package.
