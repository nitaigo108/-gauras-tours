# Gauras Tours website

A static website ready for GitHub Pages.

## Files
- `index.html` — home page
- `details.html` — journey details
- `booking.html` — booking request page
- `styles.css` — design and responsive layout
- `script.js` — mobile menu and booking form email action
- `favicon.svg` — browser icon

## Before publishing
1. Open `script.js` and replace `bookings@gaurastours.com` with your real booking email.
2. Upload all files to the root of your GitHub repository.
3. In GitHub: Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.

## Payment
The current Book Now flow sends a booking request. A live card payment/deposit button can later be connected to Stripe, Square or another provider.
